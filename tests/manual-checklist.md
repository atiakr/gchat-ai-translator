# 수동 확인 체크리스트

빌드(`npm run build`)한 `.output/chrome-mv3` 를 `chrome://extensions` 에서 "압축해제된 확장 프로그램을 로드" 로 설치한 뒤, Google Chat(https://chat.google.com) 에서 아래 항목을 차례로 확인한다. 결과 열에는 `OK` / `FAIL(메모)` 를 적는다.

사전 준비: 옵션 페이지에서 번역 서비스 하나를 고르고 유효한 API 키를 넣는다. 대상 언어는 한국어(ko), 발신 언어는 영어(en)로 둔다. 외국어 메시지를 보내 줄 상대(또는 두 번째 계정)가 있는 DM 과 스페이스를 하나씩 준비한다.

| 17 | 발신: 확인 전송 | 패널에서 번역문을 조금 고치고 "보내기" 를 누른다. | 고친 번역문이 전송되고 패널이 닫힌다. 입력창은 비워진다. | |
| 18 | 발신: 취소 | 패널에서 취소(또는 Esc)를 누른다. | 아무것도 전송되지 않고 입력창 원문이 그대로 남는다. | |
| 19 | 발신: 번역 실패 폴백 | 네트워크를 끊고 번역 버튼을 누른다. | 패널에 오류와 "다시 시도" 가 뜨고 전송되지 않는다. | |
| 20 | 발신: 전송 실패 폴백 | 보내기 버튼이 비활성인 상황(예: 첨부 업로드 중)에서 확인을 누른다. | 번역문이 입력창에 남고 "직접 Enter 로 보내세요" 안내가 뜬다. | |

| 40 | 단가와 금액 | 옵션 "사용량과 비용" 의 단가 칸을 본다. 활성 모델의 입력 단가를 다른 값으로 고치고 포커스를 뺀 뒤 "기본 단가로 되돌리기" 를 누른다. | 처음엔 그 모델의 공개 요금표 단가가 채워져 있고 확인 날짜 안내가 보인다. 고치면 "직접 입력한 단가" 안내로 바뀌고 표·팝업 금액이 새 단가로 다시 계산된다. 되돌리면 기본 단가로 돌아간다. 잘못된 값("abc", 음수)은 오류 문구가 뜨고 저장되지 않는다. | |
| 41 | 일일 토큰 상한 | 옵션 "자동 번역 한도" 의 일일 토큰 상한을 오늘 쓴 양보다 작은 값(예: 10)으로 저장한다. | 즉시 화면의 번역 표시가 모두 사라지고 발신 버튼이 숨으며, 배지에 `!` 가 뜨고 팝업과 옵션에 "오늘 토큰 상한에 도달" 배너가 보인다. 새 메시지에 아무 요청도 가지 않는다. 상한을 0 으로 되돌리면 번역이 다시 붙고 배지가 사라진다. | |
| 42 | 바로 번역: 미리보기 | 방 머리글의 "바로 번역" 스위치를 눌러 켠다. 사이드바에서 연 전체 화면 보기(방 이름·검색 아이콘 오른쪽)와 홈 목록에서 연 오른쪽 창 보기(전체 화면·닫기 아이콘 왼쪽) 모두에서 스위치가 보이고 머리글 높이가 변하지 않는지 본다. 방을 옮기면 그 방의 값으로 바뀌고, 팝업의 현재 대화방 카드에도 같은 값이 보인다. 입력창에 한국어로 적고(조합 중인 글자가 남은 채로도) 그냥 Enter 를 누른다. | 원문이 전송되지 않고 미리보기 패널이 열린다. 한글 조합을 끝내는 Enter 로는 패널이 열리지 않는다. 확인을 눌러야 번역문이 전송된다. Shift+Enter 는 줄바꿈만 한다. 다른 방에서는 그냥 Enter 가 평소처럼 원문을 보낸다. | |
| 43 | 바로 번역: 번역 불가 시 차단 | 바로 번역을 켠 방에서 팝업의 전역 스위치를 끄고 입력창에 글을 적어 그냥 Enter 를 누른다. | 메시지가 전송되지 않고 입력창 위에 "보내지 않았습니다" 안내가 뜬다. 입력창의 글은 그대로 남는다. 닫기를 누르면 안내가 사라진다. 다시 Enter 를 눌러 안내의 "이 방에서 바로 번역 끄기" 를 누르면 안내가 닫히고 그 뒤 Enter 는 원문을 보낸다(전역 스위치를 다시 켜면 토글이 꺼진 상태로 보인다). 전역 스위치를 다시 켜면 안내가 닫히고 Enter 가 미리보기를 연다. 글 없이 첨부만 올리고 Enter 를 누르면 평소처럼 전송된다. | |
