# 수동 확인 체크리스트

빌드(`npm run build`)한 `.output/chrome-mv3` 를 `chrome://extensions` 에서 "압축해제된 확장 프로그램을 로드" 로 설치한 뒤, Google Chat(https://chat.google.com) 에서 아래 항목을 차례로 확인한다. 결과 열에는 `OK` / `FAIL(메모)` 를 적는다.

사전 준비: 옵션 페이지에서 번역 서비스 하나를 고르고 유효한 API 키를 넣는다. 대상 언어는 한국어(ko), 발신 언어는 영어(en)로 둔다. 외국어 메시지를 보내 줄 상대(또는 두 번째 계정)가 있는 DM 과 스페이스를 하나씩 준비한다.

| # | 항목 | 절차 | 기대 결과 | 결과 |
|---|------|------|-----------|------|
| 1 | 과거 메시지 번역 | 외국어 메시지가 여러 개 있는 방을 연다. | 화면에 보이는 수신 메시지마다 본문 아래에 로딩 표시가 잠깐 떴다가 한국어 번역 블록으로 바뀐다. 내 메시지에는 아무것도 붙지 않는다. | |
| 2 | 스크롤로 더 불러온 메시지 | 같은 방에서 위로 스크롤해 과거 메시지를 더 불러온다. | 새로 나타난 수신 메시지도 번역된다(방당 상한 200건을 넘긴 것은 "상한 초과" 표시). | |
| 3 | 새 메시지 번역 | 상대가 외국어 메시지를 새로 보낸다. | 도착 직후 로딩 → 번역 블록. 같은 메시지를 다시 요청하지 않는다(새로고침 뒤 즉시 표시). | |
| 4 | 같은 언어 건너뜀 | 상대가 한국어 메시지를 보낸다. | 아무 표시도 붙지 않는다(로딩 표시가 남지 않는다). | |
| 5 | 본문 없음 | 상대가 이모지만, 또는 이미지/파일만 보낸다. | 아무 표시도 붙지 않는다. | |
| 6 | 긴 메시지 건너뜀 | 옵션에서 길이 상한을 50자로 줄이고 상대가 더 긴 메시지를 보낸다. | "긴 메시지라 건너뜀" 한 줄만 표시되고 번역 요청은 없다(네트워크 탭·사용량으로 확인). | |
| 7 | 수정 재번역 | 상대가 이미 번역된 메시지를 수정한다. | 기존 번역 블록이 로딩 상태로 바뀐 뒤 새 본문의 번역으로 교체된다. | |
| 8 | 오류 표시·재시도 | 틀린 키(또는 네트워크 차단)로 메시지를 받는다. | 오류 한 줄과 "다시 시도" 버튼. 키를 고치고(또는 네트워크 복구) 버튼을 누르면 그 메시지만 다시 번역된다. | |
| 9 | 전역 끄기 | 팝업에서 전역 스위치를 끈다. | 화면의 번역 블록·로딩·오류 표시가 즉시 모두 사라지고, 발신 번역 버튼도 숨는다. 새 메시지가 와도 아무것도 붙지 않는다. 다시 켜면 화면의 수신 메시지가 다시 처리되며 이미 번역했던 것은 즉시 뜬다. | |
| 10 | 키 없음·틀린 키 | 활성 서비스의 키를 지운다 / 틀린 키를 넣고 연결 테스트를 실패시킨다. | 전역 끄기와 같은 화면 동작(블록 제거·버튼 숨김). 배지에 상태가 표시된다. | |
| 11 | 방별 끄기 | 팝업에서 현재 방의 수신 번역을 끈다. | 그 방의 번역 블록이 즉시 사라지고 새 메시지도 처리하지 않는다. 발신 번역 버튼은 그대로 남는다. 다른 방은 영향 없다. 다시 켜면 다시 처리된다. | |
| 12 | 원문 숨기기 | 옵션에서 "원문 숨기기" 를 켠다. | 번역된 메시지의 원문이 접히고 번역문만 보인다. 토글로 원문을 펼칠 수 있다. 끄면 원문이 다시 보인다. 이미 붙어 있던 블록에도 즉시 적용된다. | |
| 13 | 발신: 버튼으로 번역 | 입력창에 한국어를 적고 보내기 버튼 옆 번역 버튼을 누른다. | 미리보기 패널에 원문과 영어 번역이 뜬다. 아직 아무것도 전송되지 않는다. | |
| 14 | 발신: 서식·멘션 경고 | 입력창에 @멘션이나 굵게 서식을 넣고 번역 버튼을 누른다. | 패널에 "멘션/서식이 사라집니다" 경고가 뜬다. | |
| 15 | 발신: 언어 변경 | 패널에서 언어를 일본어로 바꾼다. | 번역문이 일본어로 다시 생성된다. | |
| 16 | 발신: 기본 언어 저장 | "이 방의 기본 언어로 저장" 을 체크하고 전송한다. | 다음에 같은 방에서 번역 버튼을 누르면 그 언어가 기본으로 선택된다. 팝업/옵션의 방별 설정에도 반영된다. | |
| 17 | 발신: 확인 전송 | 패널에서 번역문을 조금 고치고 "보내기" 를 누른다. | 고친 번역문이 전송되고 패널이 닫힌다. 입력창은 비워진다. | |
| 18 | 발신: 취소 | 패널에서 취소(또는 Esc)를 누른다. | 아무것도 전송되지 않고 입력창 원문이 그대로 남는다. | |
| 19 | 발신: 번역 실패 폴백 | 네트워크를 끊고 번역 버튼을 누른다. | 패널에 오류와 "다시 시도" 가 뜨고 전송되지 않는다. | |
| 20 | 발신: 전송 실패 폴백 | 보내기 버튼이 비활성인 상황(예: 첨부 업로드 중)에서 확인을 누른다. | 번역문이 입력창에 남고 "직접 Enter 로 보내세요" 안내가 뜬다. | |
| 21 | 발신: 내 원문 표시 | 17 번으로 보낸 메시지를 화면에서 본다. | 내 메시지 아래에 "원문: (한국어)" 가 작게 표시된다. 새로고침 뒤에도 표시된다. | |
| 22 | 라이트·다크 테마 | Google Chat 테마를 라이트 ↔ 다크로 바꾼다. | 번역 블록·발신 버튼·패널의 색이 각 테마에 맞게 바뀌고 글자가 잘 읽힌다. | |
| 23 | 한국어·영어 UI | Chrome 언어를 영어로 바꿔 다시 연다. | 블록·버튼·패널·팝업·옵션의 문구가 영어로 나온다. 한국어로 되돌리면 한국어. | |
| 24 | 연결 테스트 | 옵션에서 서비스별 "연결 테스트" 를 누른다. | 유효한 키면 샘플 번역과 성공 표시, 틀린 키면 오류 종류가 표시되고 틀린 키 상태가 해제/설정된다. | |
| 25 | 기록 지우기 | 옵션에서 "번역 기록 지우기" 를 누른다. | 확인 뒤 기록이 비고, 같은 메시지가 다시 그려질 때 다시 요청된다(로딩 표시가 다시 뜬다). 내 원문 표시도 사라진다. | |
| 26 | 깨짐 배지 | `src/gchat/selectors.ts` 의 메시지 컨테이너 셀렉터를 일부러 틀리게 고쳐 빌드·설치하고 방을 연다. | 60초 뒤 확장 아이콘 배지에 깨짐 표시가 뜬다. 셀렉터를 되돌려 다시 설치하면 배지가 해제된다. | |
| 27 | 단축키(입력창) | 입력창에 글을 적고 Ctrl+Shift+Enter(Mac: Cmd+Shift+Enter)를 누른다. | 번역 패널이 열리고 메시지는 전송되지 않는다. 두 번 빠르게 눌러도 패널은 한 번만 열린다. | |
| 28 | 단축키(Chrome 설정) | `chrome://extensions/shortcuts` 에서 "보내기 전 번역" 에 다른 키를 매긴 뒤 입력창에서 누른다. | 같은 패널이 열린다. 전역 스위치가 꺼져 있으면 아무 일도 없다. | |
| 29 | 설치 직후 옵션 페이지 | 확장을 제거했다가 다시 설치한다. | 설치 직후 옵션 페이지가 자동으로 한 번 열린다. 이후 재시작에는 열리지 않는다. | |
| 30 | 커스텀 주소 권한 요청 | 옵션에서 OpenAI 호환 서비스를 고르고 주소(`https://example.com/v1`)를 저장한다. | 그 출처에 대한 권한 요청 대화상자가 뜬다. 허용하면 연결 테스트가 가능하다. | |
| 31 | 커스텀 주소 권한 거부 | 30 번에서 권한을 거부한다. | 옵션에 권한이 없다는 안내가 남고 호출이 되지 않는다. 다시 저장하면 다시 요청한다. | |
| 32 | 방 전환 | 번역 블록이 붙은 방에서 사이드바로 다른 방으로 옮겼다가 돌아온다. | 이전 방의 블록이 새 방에 남지 않는다. 새 방의 수신 메시지가 번역되고, 돌아오면 기록에 있는 것은 즉시 뜬다. | |
| 33 | 화면 안정성 | 모든 항목을 진행하는 동안 Google Chat 의 입력·전송·스크롤·스레드 열기를 평소처럼 쓴다. | 확장 때문에 느려지거나 멈추거나 레이아웃이 깨지지 않는다. 콘솔에 확장이 던진 미처리 예외가 없다. | |
| 34 | 단축키가 원문을 먼저 보내지 않음 | 입력창에 글을 적고 Ctrl+Shift+Enter(Mac: Cmd+Shift+Enter)를 누른다. | 미리보기 패널만 열리고 원문이 전송되지 않는다(대화에 원문 메시지가 나타나지 않는다). 그냥 Enter 는 평소처럼 원문을 보낸다. | |
